# 새 세션 헤드 에이전트 인계 프롬프트 (2026-10-23 작성)

아래 구분선 안의 내용을 노트북의 새 Claude Code 세션 첫 메시지로 붙여 넣는다.

---

이 저장소는 포켓몬 챔피언스 랭크배틀 뉴비를 위한 "한 턴 복기 코치"다. 패배한 한 턴을 자연어로 입력하면, 상대 빌드별 데미지 계산과 시즌 통계로 "왜 졌지 → 상대가 뭘 들었지 → 어떻게 이기지"에 답한다. 스택은 FastAPI(`server/`)와 순수 HTML/JS(`web/`)이고, 계산은 `prep/calculator.py`·`prep/review.py`에 있다. 비상업 포트폴리오 프로젝트다. 목표 직무는 서비스 기획/풀스택이고, 수익화는 하지 않기로 결정했다.

너는 이 세션의 헤드 에이전트다. 이전 작업은 SSAFY PC에서 했고, 오늘 이 노트북으로 옮겨 왔다. 이전 대화 기록은 없다. 맥락은 저장소 문서에 있다.

## 1. 먼저 읽을 것 (순서대로, 읽기 전에 아무것도 고치지 않는다)
1. `CLAUDE.md`: "Start here" 절. 사용자 지시와 실행 명령이 있다.
2. `docs/HANDOFF-machine-migration.md` 맨 위 ★ 절: 환경 복구 순서와 설치할 스킬
3. `docs/HANDOFF-friend-test-1.md`: 1차 친구 테스트 피드백. 다음 개발 작업 F1~F12와 우선순위가 있다.
4. `TODOS.md` 맨 위 "운영" 절(O1~O4)
5. `docs/designs/portfolio-ops.md`: 배포·사용자 추적 설계(승인됨, 접근 B)
6. `docs/agent-memory/`: 이전 agent의 메모리. 사용자 선호와 결정 배경이 있다. 이 노트북의 `~/.claude/projects/<이 저장소 경로>/memory/`에 아직 없으면 복사해 둔다.
7. 제품 설계와 결정 기록이 필요할 때만 `docs/designs/loss-review-coach.md`(맨 위 배너 개정 v1.4부터)와 `docs/designs/loss-review-coach.ceo-review.md`를 읽는다. 여기 있는 D·R·C 번호 결정은 다시 논의하지 않는다.

## 2. 첫 작업: 환경 복구 확인 (★ 절 B·C)
사용자가 이미 했을 수 있으니, 하기 전에 상태부터 확인하고 빠진 것만 한다.
- `git status`, `git log --oneline -3`: GitHub에서 clone한 상태인지 확인한다.
- 백업 압축본(`AIpjt-backup-20261023.zip`)을 풀어 두었는지 확인한다. `data/raw/pokedb/`, `chroma_db/`, `data/logs/`가 있어야 한다. 없으면 사용자에게 압축본 위치를 묻는다.
- `.venv` 생성과 `pip install -r requirements.txt`
- `.env`: 사용자가 새 OpenAI API 키를 넣어야 한다. `OPENAI_BASE_URL`은 비우고, `INVITE_TOKENS`를 넣는다. **키 값을 대화에 출력하지 않는다.**
- 테스트 `.venv/Scripts/python -m unittest discover -s tests -t .`는 86개가 통과해야 한다.
- 임베딩 호환을 확인한다(HANDOFF-machine-migration "노트북에서 확인할 것" 3). 저장된 벡터와 코사인이 약 1.0이면 재색인하지 않는다.
- 설치할 스킬은 ★ 절 C 표를 따른다. gstack은 필수이고, superpowers, agent-skills, ponytail도 설치한다. 하위 스킬이 슬래시 명령으로 등록되지 않으면 `~/.claude/skills/gstack/<이름>/SKILL.md`를 직접 읽어 실행한다. 헬퍼가 bun 오류로 깨지면 `npm i -g bun`을 실행한다.
- 결과를 사용자에게 짧게 보고한다. 무엇이 됐고, 무엇이 남았고, 사용자가 할 일이 무엇인지 적는다.

## 3. 그다음 작업 후보 (사용자에게 순서를 확인받고 시작)
- **F1~F12 수정** (`docs/HANDOFF-friend-test-1.md` 우선순위표)
  - 1순위 F1: 최악 빌드부터 내려가며 계산. 사용자의 새 지시이고, 개정 v1.4 계산표 규칙을 바꾼다. 통계 기반 "내 빌드 가정"을 대체할지 먼저 묻는다.
  - 2순위 F9: 성격을 비우면 생명의구슬 줄이 사라진다. 재현 코드가 문서에 있다.
  - 모든 수정은 테스트를 먼저 쓴다. 계산 기대값은 시중 계산기(스마트누오·Showdown)와 같아야 한다.
- **O3 친구 테스트 판정(C-O6):** 친구에게 받는 테스트 뒤 질문 A~E 답이 아직 없다. 사용자가 받아 오면 `docs/friend-test-kit.md` 3단계 판정표를 채운다.
- **O4 클라우드 배포(설계 B):** Dockerfile, 영구 디스크가 있는 VM, GitHub Actions, HTTPS, `visit` 이벤트 퍼널, `/changelog`. VM 업체, 월 비용 한도, 도메인은 사용자가 정한다(설계 Open Questions 1·2). 정해지기 전에는 만들지 않는다.

## 4. 반드시 지킬 것
- **커밋·푸시는 사용자가 직접 한다.** 너는 하지 않는다. 변경 뒤에는 커밋할 단위와 메시지만 제안한다.
- 데이터 우선순위
  - PokeAPI > pokedb(도구·채용률) > Smogon(성격·SP·특성 보충). champions-data는 빈칸 보충 전용이다.
  - 현재 시즌(M-7) 통계는 받을 수 없다. pokedb는 M-6까지이고, 그 뒤는 Smogon(시뮬레이터) 기준이다.
  - 두 기준의 결과가 크게 다르면 둘 다 보이고, Smogon은 시뮬레이터 데이터라고 밝힌다.
- pokedb는 오픈데이터 파일만 쓴다. 페이지 크롤링은 금지다. Bulbapedia 요청은 5초 간격을 둔다.
- `data/logs/`에는 친구 테스트 원문이 있다. 커밋하지 않고, 외부 서비스(공개 페이지, 아티팩트 등)에 올리지 않는다. 친구에게 "다른 사람에게 보내지 않는다"고 동의를 받았다.
- 화면 작업 전에는 `DESIGN.md`를 읽는다. 벗어나려면 사용자에게 묻는다.
- 서브에이전트에게 일을 나눌 때는 작업마다 읽을 파일과 위 4절 규칙을 프롬프트에 넣는다. 서브에이전트는 이 대화를 보지 못한다. 결과는 헤드가 확인한 뒤 사용자에게 보고한다.
- 답변은 한국어로 한다. 사용자가 고른 결정은 다시 묻지 않는다.

## 5. 알려진 함정
- 서버 기록에서 extract 사건은 문장을 남기지 않는다(F12). 실패한 입력을 분석하려면 이 기록부터 고쳐야 한다.
- 결과 화면(headline·계산표)은 기록되지 않는다. 지난 테스트 화면은 같은 입력으로 다시 계산해 복원했다(요약 LLM이 꺼져 있어 결정적이다).
- 친구에게 링크를 줄 때는 `cloudflared tunnel --url http://127.0.0.1:8000`을 쓴다. 막히는 망이면 `--protocol http2`를 붙이고, 그래도 안 되면 Pinggy(무료 60분)를 쓴다.
