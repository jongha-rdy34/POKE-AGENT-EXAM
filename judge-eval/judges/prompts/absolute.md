# 절대 평가

아래 패킷은 서비스 {{APP_LABEL}} 하나에 대한 자료입니다. 다른 서비스와 비교하지 말고 이 서비스만 평가하세요.

## 루브릭 (항목마다 1~5 정수)

### accuracy — 기능 정확성
- 5: 계산·판정 결과가 객관 지표와 화면에서 일관되게 맞고, 근거(수치·조건)를 함께 보여 준다
- 4: 대부분 맞고, 틀리거나 빠진 경우가 드물며 사소하다
- 3: 맞는 결과와 틀리거나 근거가 불분명한 결과가 섞여 있다
- 2: 핵심 결과에 오류가 여러 번 보이거나 근거를 확인할 수 없다
- 1: 핵심 기능이 동작하지 않거나 결과가 대부분 틀렸다

### purpose_fit — 목적 대비 완성도 (서비스 범위가 아니라, 스스로 밝힌 목적을 얼마나 달성했나)
- 5: 밝힌 목적의 핵심 질문에 끝까지 답하고, 빠진 단계가 없다
- 4: 목적은 달성하지만 일부 단계가 약하거나 사용자가 보충해야 한다
- 3: 목적의 절반 정도만 달성한다
- 2: 목적과 관련된 기능은 있으나 실제 답에 이르지 못하는 경우가 많다
- 1: 밝힌 목적을 달성하지 못한다

### usability — 사용성 (처음 온 사용자가 막힘 없이 쓸 수 있나)
- 5: 첫 화면에서 할 일이 분명하고, 입력 실수에도 다음 행동을 안내한다
- 4: 대체로 막힘이 없고, 한두 군데 설명이 부족하다
- 3: 설명을 읽거나 시행착오를 거쳐야 쓸 수 있다
- 2: 여러 단계에서 무엇을 해야 할지 알기 어렵다
- 1: 첫 사용자가 혼자서는 핵심 기능까지 가기 어렵다

### ui — UI 시각 품질 (데스크톱·모바일 캡처 기준)
- 5: 위계·여백·정렬·글자 크기가 일관되고, 모바일에서도 깨지지 않는다
- 4: 대체로 정돈됐고, 사소한 어긋남이 있다
- 3: 쓸 수는 있으나 정렬·밀도·대비에 눈에 띄는 문제가 있다
- 2: 겹침·잘림·읽기 어려운 대비 등 문제가 여러 곳이다
- 1: 화면이 깨지거나 읽기 어렵다

### code — 코드 품질 (발췌 기준: 가독성, 구조, 오류 처리)
- 5: 책임이 잘 나뉘고 이름이 명확하며, 입력 검증과 오류 처리가 일관된다
- 4: 대체로 읽기 쉽고, 오류 처리에 작은 빈틈이 있다
- 3: 동작은 이해되나 구조나 오류 처리가 고르지 않다
- 2: 읽기 어렵거나 오류 처리가 자주 빠져 있다
- 1: 구조를 파악하기 어렵고 오류 처리가 거의 없다
